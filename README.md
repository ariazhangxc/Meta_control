# Meta_control
This repository contains the full modeling and analysis pipeline for a reliability-guided meta-control model of intuitive physics.

The pipeline includes RNN data generation, RNN training, meta-control model evaluation and parameter selection, and the analyses used to generate the final figures.

## Pipeline

Run the four notebooks in the following order:

```text
rnn_data_prep.ipynb
        ↓
rnn_training.ipynb
        ↓
meta_control_grid_search.ipynb
        ↓
final_figures.ipynb
```

Each notebook uses the outputs of the previous stage.

### 1. `rnn_data_prep.ipynb`

Generates the RNN training and testing data.

The training set contains 6,000 generated scenes. Physics is simulated until the ball first reaches the goal or the ground. Scenes without a terminal event within the allowed simulation window are rejected. After the terminal event, the ball remains fixed for an additional 60 frames.

The notebook also processes the 106 experimental scenes used for testing:

* 48 Experiment 1 scenes
* 58 Experiment 2 scenes

Rendered scenes are downsampled from `800 × 1024` to `100 × 128` and stored as compressed frame and ball-position caches.

Main outputs:

```text
rnn_training_data/
rnn_testing_data/
compressed_frame_cache_100x128/
ball_position_cache/
```

The data-preparation and training notebooks use the same scene-relative cache IDs, so the generated caches can be read directly by the training notebook.

### 2. `rnn_training.ipynb`

Trains the RNN using the data generated by `rnn_data_prep.ipynb`.

Each training sample contains a consecutive 15-frame visual history taken before the first terminal event. The model predicts the future ball trajectory together with its expected prediction error.

The prediction target begins at offset 0, corresponding to the ball position at the final input frame, and continues through the remaining trajectory, including the 60 frozen post-event frames.

Testing uses the first 15 frames of each of the 106 experimental scenes.

The model is trained for 150 epochs. The model after the final training epoch is saved and used by all downstream analyses.

Main output:

```text
rnn_training_results/
└── lambda_0_2_offset0_everypoint_sliding15_nonfreeze_windows20_epochs150/
    └── final_rnn_model.pt
```

The training loss combines position prediction error with RNN error-prediction loss using an error-loss weight of `0.2`.

A CUDA-capable GPU is required for this notebook.

### 3. `meta_control_grid_search.ipynb`

The grid search evaluates 275 parameter combinations for the reliability-guided meta-control model:

```text
Abstraction length A:
50, 60, 70, 80, 90, 100, 110, 120, 130, 140, 150

Simulation length S:
20, 30, 40, 50, 60

Predicted-error threshold e:
20, 21, 22, 23, 24
```

Grid-search results are written to:

```text
meta_control_grid_search/
```

After the grid search, the notebook reruns the selected model:

```text
A = 150
S = 20
e = 22
```

and saves its complete trajectories and scene-level results under:

```text
meta_control/
└── A150_S20_e22/
    ├── hybrid_scene_summary.csv
    ├── hybrid_predictions/
    └── hybrid_overlay_plots/
```


### 4. `final_figures.ipynb`

Runs the final RNN, meta-control, and model-comparison analyses and generates the figures used in the paper.

The notebook first regenerates the RNN analysis datasets directly from the trained model and prepared testing data, including:

```text
rnn_analysis/
├── rnn_predictions_until_contact.csv
├── rnn_terminal_summary.csv
├── collision_labels/
│   └── rnn_labeled_container_or_line_circle_phases.csv
└── mixed_model/
    └── mixed_model_row_level_data.csv
```

It then performs the final analyses, including:

* RNN trajectory and predicted-error analyses
* collision-stage and mixed-effects analyses
* RNN-predicted error and pupil-size analyses
* meta-control model trajectory visualization
* human and model reasoning-time analyses
* human accuracy analyses
* eye-movement analyses during abstraction and simulation
* scene-level abstraction proportion, saccades, and pupil size
* direct comparison between the meta-control and blended models


Preprocessed human behavioral and eye-tracking datasets in the `data` directory are obtained from [`eyetracking_physics`](https://github.com/flxsosa/eyetracking_physics).

For model-comparison analyses, this project uses `blended_model/model_predictions.csv` from the same repository, together with outputs from the selected meta-control model.

Intermediate analysis tables are written under:

```text
final_figure_analysis/
```

All final figures are automatically saved as 300 dpi PNG files under:

```text
final_figures/
```

## Dependencies

The notebooks require Python 3 and Jupyter, together with the main Python packages:

```text
numpy
pandas
Pillow
imageio
matplotlib
scipy
statsmodels
pydantic
torch
pymunk
IPython
```


The project also requires the dependencies used by [`physics_abstraction_master`](https://github.com/flxsosa/physics_abstraction).

RNN training is configured to require a CUDA-capable GPU. The downstream meta-control and analysis notebooks can run independently from the training process once the trained model and generated caches are present.

## Reproducing the analysis

For a complete run from the beginning:

1. Place the four notebooks, `physics_abstraction_master`, behavioral data, eye-gaze data, and blended-model predictions in the folder structure shown above.
2. Run `rnn_data_prep.ipynb` from beginning to end.
3. Run `rnn_training.ipynb` to train the RNN for 150 epochs.
4. Run `meta_control_grid_search.ipynb` to evaluate the parameter grid and export the selected `A150_S20_e22` meta-control model.
5. Run `final_figures.ipynb` to regenerate the analysis tables and final figures.
